# connector-runtime
Goal: poll connectors and emit deduped events. `createConnectorRuntime({connector, cursors, sink, clock})` exposes `runOnce(tenantId)`: page through connector-kit list with cursor, for each item emit change event to injected `sink` once (change-cursor seen(tenantId,eventId)), persist cursor only past pages whose items were delivered or quarantined, resume after crash, BAD_CURSOR restarts full scan. Uses @anvesx/connector-kit, @rag/change-cursor, @anvesx/core-types.

Event identity includes the canonical ACL (changed ACL at the same version emits one). A sink failure is collected per document (RunResult.failures), does not block later documents, is retried up to maxAttempts (default 3) then quarantined (RunResult.quarantined). Runs for one tenant are serialised.
Acceptance: first run emits all, second run emits none, modified file emits one, ACL change emits one, failing doc does not block others and is quarantined after 3 runs, concurrent runs lose nothing, sink failure does not advance cursor past the failed page, crash-resume, tenant isolation.
