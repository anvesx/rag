# query-service
Goal: ACL-safe search. `createQueryService({index, registry})` exposes `search({query, limit, principal, embedding})`: hybrid-search with acl-filter clause for the principal, page the index (offset/limit, cap `maxCandidates` default 1000, `truncated` when capped), hydrate pointers from registry, drop tombstoned and cross-tenant pointers, return Pointer[]. Optional injected `liveAcl(tenantId, docIds, principal)` runs after the cached filter via `searchLive`: `deny` drops, `unknown`/throw/timeout fail closed and are counted (`liveUnverified`). Sync `search` throws `LIVE_ACL` when a verifier is configured. Uses hybrid-search `offset` (fixed 1000-deep fused window, offset+limit <= 1000; see README). Uses @rag/hybrid-search, @rag/acl-filter, @rag/pointer-registry, @brain/core-types.

Acceptance: user/group/zone visibility matrix, tenant isolation, deleted docs hidden, limit bounds, empty query typed error, ACL revoked after index still hidden, short pages filled by paging, cap truncation, live deny/unknown/timeout fail closed.
