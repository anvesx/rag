# index-service
Goal: apply change events to the index. `createIndexService({registry, index, chunk, embed, fetchText?})` exposes `apply(event)`: upsert pointer; if change=="unchanged" do nothing; if updated/created fetch text via injected `fetchText(pointer)` (the fetched text must hash, sha-256 hex of the UTF-8 text, to `pointer.contentHash`, else `IndexServiceError("HASH_MISMATCH")` before any index write and the prior pointer is restored; or use the optional `content: {text, contentHash}` on the upsert event, verified against the pointer's contentHash and the text itself, else `IndexServiceError("HASH_MISMATCH")` before any state change; no `fetchText` call then). `fetchText` is optional: when it is absent, an upsert that needs indexing must carry `content`, else `IndexServiceError("INVALID_EVENT")` (previous registry row restored, replay with content succeeds; an `unchanged` upsert still needs nothing). Then chunk it, embed via injected `embed(texts)`, replace the doc's chunks in hybrid-search with one atomic `index.replace(docId, tenantId, chunks)` (all-or-nothing). Deleted event tombstones pointer and removes chunks. Uses @rag/pointer-registry, @rag/chunker, @rag/hybrid-search, @anvesx/core-types.

Failure rules: on any failure the prior pointer is restored with the intersection of old and new ACL (also written to the index via `updateAcl`), so a revocation is never undone and access never widens; the error is still thrown. A failed `replace` throws `IndexServiceError("INDEX_FAILED")` and leaves the old chunks searchable, with the prior pointer restored. The index stores no body text (pointer-only).
Acceptance: created/updated/unchanged/deleted paths, idempotent replay, partial failure leaves old chunks intact (no half-indexed doc), tenant isolation (same docId in two tenants), ACL change reindexes ACL columns.
