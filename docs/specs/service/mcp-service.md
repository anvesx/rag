# mcp-service
Goal: run the MCP search tool over real transports. `startMcpServer({search, principalFor, transport:"stdio"|"http", port?})` builds an McpServer, registers @rag/mcp-search-tool, connects stdio or Streamable HTTP, returns {close()}. Principal derived from session/auth header via injected resolver, never from tool input.

Acceptance: REAL transport integration tests (spawn stdio child process with MCP SDK client; HTTP on ephemeral port), unauthenticated request rejected, graceful close, concurrent clients.
Rules: package services/NAME, name @rag/NAME, depends ONLY on @rag/* features + third-party libs (never another service). TDD: write failing tests first under tests/{unit,integration}. Files <=80 lines, folders <=5 files (README exempt), src/ + tests/ + README.md in every package and README in every src subfolder. ESM TypeScript, node:sqlite, vitest 5, zod. Copy package.json/tsconfig/vitest/stryker config shape from features/mcp-search-tool. Inject clock/IO. Typed errors. Run pnpm structure, pnpm exec biome check ., pnpm --filter @rag/NAME test/typecheck before reporting.
Hardening (HTTP): configurable `maxSessions` (1000), `maxSessionsPerPrincipal` (20), `idleTimeoutMs` (30 min, injected timers); over-limit initialize -> 429 generic body. DNS rebinding: Host/Origin allow-lists (default loopback names with the bound port), disallowed -> 403, also enabled on the SDK transport (`enableDnsRebindingProtection`/`allowedHosts`/`allowedOrigins`). Mutation: `pnpm --filter @rag/mcp-service mutation` runs Stryker with `inPlace: true` (the sandbox copy breaks `tsconfig` extends in the global-setup build); threshold 80.
