# rag app
Goal: the runnable RAG server. apps/rag (@rag/app) composes the three modules: ingestion (connector -> index), retrieval (MCP search over HTTP/stdio), governance (audited search + verify + checkpoint). `createRagApp({connector, cursors, clock, embed, embedQuery, fetchText, principalFor, auditDbPath, anchorPath, transport, port?})` builds an in-memory/file-backed registry and hybrid-search index, an audit chain+service, an index-service, wires ingestion, and exposes `{ingest(tenantId), search(...), verify(tenantId), checkpoint(tenantId), close(), port}`. Search served over MCP must go through governance so every search writes one audit row. A bin entry (src/bin.ts) reads env config (RAG_PORT, RAG_AUDIT_DB, RAG_ANCHOR) and starts it with a demo in-memory connector only when RAG_DEMO=1.

Acceptance (integration, real components, no mocks of our own packages): ingest 3 docs, MCP HTTP client search returns the visible ones; ACL-hidden and cross-tenant docs never returned; every search appends exactly one audit row and verify(tenant) is ok; tampering with the audit db makes verify fail; unauthenticated 401; close() idempotent and frees port.
Rules: apps/rag, depends only on @rag/* modules and features/services needed for composition (never another app). Compose, write no new core logic. Addendum (live ACL): `fetchText` is optional (default: tenant connector fetch with tenant credential). Optional `userTokenFor(principal)` and `liveAclTimeoutMs` turn on a connector-based live ACL: every search fetches each hit through the tenant connector with the user's own token (success allow, ConnectorError NOT_FOUND deny, anything else unknown); only allow keeps a hit; no token, unknown tenant, error or timeout fails closed. Search then goes through retrieval (toOutcomeFn + auditedOutcome + toSearchFn) and rejects with RetrievalError LIVE_ACL when nothing can be verified (one audit row with detail {count:0, outcome:"failure", code:"LIVE_ACL"}; MCP "Search failed"; a failed audit write fails the request). Same audit row shape as governance. Without userTokenFor, governance is used unchanged. Limit: whole-document fetch per hit.
Addendum (review fixes): `dataDir` (env RAG_DATA_DIR) puts registry, search index and cursor store on disk; `cursors` becomes optional. Bearer tokens are `user:tenant:hmac-sha256-hex(secret, "user:tenant")` with secret from RAG_AUTH_SECRET (min 32 chars, else startup error), compared with timingSafeEqual; `mintToken` is exported; the unsigned token works only with RAG_DEMO=1 and no secret. Injectable `logger` ({error,warn,info}, default JSON lines on stderr) is passed to the MCP service so failure causes are logged without query text or tokens. Closed: the app passes `known: (tenantId) => liveIds(registry, tenantId)` (live pointer ids, paged with afterId) so docs deleted at source while down are tombstoned on the next full run.

Addendum (hardening): Bearer tokens are now `user:tenant:exp:hmac-sha256-hex(secret, "user:tenant:exp")`, `exp` in epoch seconds, signed/compared with timingSafeEqual. A correctly signed token at or past `exp` throws `TokenExpiredError` (code TOKEN_EXPIRED, message "unauthenticated: token expired"); everything else throws "unauthenticated". The old 3-part `user:tenant:hmac` form carries no expiry and is rejected. `RAG_AUDIT_KEY` must be at least 32 characters and is required when `RAG_AUTH_SECRET` or `RAG_DATA_DIR` is set; otherwise demo mode falls back to the public demo key with a warning.
