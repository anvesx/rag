# retrieval module
Goal: one call that wires query-service into mcp-service. `createRetrieval({index, registry, principalFor, transport, port?})` builds createQueryService, adapts its sync search to the async SearchFn (query embedding via injected `embedQuery(text)`), starts startMcpServer, returns {close(), port}. Audit (required): `audit` (@rag/audit-service) and `auditKey` (non-empty master secret) are required deps; missing -> RetrievalError CONFIG at construction. Every search records one row (actor, action="search", target=HMAC(HMAC(auditKey, tenant), trimmed query), detail={count}) before results return; a failed write fails the search closed (safe MCP error, no pointers); failed searches leave no row, except a LIVE_ACL refusal. The query is validated and trimmed before embedding. Logic is a small duplicate of governance (modules cannot depend on modules). Live ACL and paging (addendum): search goes through query-service `searchLive` (pages the index with offset up to maxCandidates; optional liveAcl, liveAclTimeoutMs, timer, maxCandidates options pass through). The handle gains `search(request)`: audited, typed result `{ok:true, pointers, truncated, scanned, liveDenied, liveUnverified, degraded?}` (degraded:true when results survived with liveUnverified>0) or `{ok:false, code:"LIVE_ACL"}` (verifier error/timeout, or nothing returned while some hit was unverified). LIVE_ACL fails closed: no pointers, one audit row (detail {count:0, outcome:"failure", code:"LIVE_ACL"}; a failed write fails the request with AUDIT), MCP error "Search failed", RetrievalError code LIVE_ACL. `truncated` is not exposed over MCP, only via `handle.search`. Also exports `createConnectorLiveAcl({connectorFor, userTokenFor, pointerFor})`: a LiveAcl that fetches each hit via connector-kit with the user's token (ok allow, NOT_FOUND/FORBIDDEN deny, else unknown; bounded concurrency, default 8; deadline AbortSignal; connector without enforcesUserToken:true -> CONFIG). Acceptance: real HTTP MCP client calls `search` end to end against a real in-memory index+registry; ACL-hidden docs never returned; unauthenticated 401; embedQuery failure becomes safe MCP error.
