# governance module
Goal: audited access. `createGovernance({audit, query})` wraps a search function so every search records an audit event (actor=principal.userId, action="search", target=keyed digest, detail=result count) via audit-service before returning, and exposes `verify(tenantId)` and `checkpoint(tenantId)`. Target digest = HMAC-SHA256(HMAC-SHA256(auditKey, tenantId), trimmed query); `auditKey` (string or bytes) is a required injected dep and missing/empty -> GovernanceError CONFIG at construction. Audit failure fails closed (no results returned). Acceptance: every search leaves one verifiable audit row; tamper detected via audit-service; audit store failure blocks results; tenants independent; raw query text never stored (keyed digest only); same query+tenant same digest, different tenant different digest.
